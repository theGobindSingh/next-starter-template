# Voice matching

Read when the user supplies a writing sample, says "in my voice", or the text goes out under their name.

## Sources of voice, best first

1. A sample the user wrote and owns (emails, posts, old essays, chat messages).
2. The user's own messages in this conversation. They are a free sample of how the person actually writes: capitalization, punctuation, sentence length, slang, spelling variety.
3. Stated preferences ("I hate emojis", "keep it formal").
4. The register (see `registers.md`) when nothing else exists.

Do not imitate a named third person to pass as them. Writing "in the style of" a famous author for a clearly labelled pastiche is different from ghostwriting in a real colleague's voice to deceive.

## What to measure in a sample

Build a quick profile before writing. Read it, don't just count, but these are the dimensions that matter:

| Dimension | Look for |
| --- | --- |
| Sentence length | typical length and spread; do they ever write one-word sentences? 50-word ones? |
| Paragraphing | one-liners? long blocks? line breaks in chat? |
| Openings | do they greet? start mid-thought? start with "So" or "Ok"? |
| Punctuation | dashes (which kind, spaced?), semicolons, parentheses, ellipses, exclamation marks, Oxford comma, final periods in chat |
| Capitalization | lowercase starts, ALL CAPS emphasis, title case habits |
| Contractions | always, sometimes, never |
| Vocabulary level | plain or elevated; field jargon; favorite words and phrases ("basically", "tbh", "kinda") |
| Hedging | "I think", "probably", "not sure but" vs flat assertions |
| Humor | dry, self-deprecating, none; emoji or "haha" use |
| Spelling variety | US/UK/Indian English; recurring typos they don't care about |
| Stance | direct opinions or diplomatic; how they disagree |
| Sign-offs | "Thanks", "Cheers", "-S", nothing |

Write the profile down in two or three lines for yourself, then draft to it. The sample overrides the default rules in this skill: if they use dashes, use dashes at about their rate; if they never use contractions, don't add them.

## Don't upgrade their voice

If they write "stuff" and "a bunch", don't turn it into "various elements". If their sentences are plain, don't make them elegant. The most common failure in voice matching is producing a better-written text that no longer sounds like them.

## Don't caricature it either

A voice profile is a set of tendencies, not a checklist to max out. If they sometimes use "lol", one in a message is plenty. Overusing someone's tics reads as parody.

## Long-term voice

When the user writes regularly (emails, posts), keep the profile consistent across pieces. Consistency across time is a human signal; Wikipedia notes that a sudden shift in style between someone's older writing and their new writing is one of the ways AI use gets noticed.
